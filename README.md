# Renshuu Offline

Private tool to do Renshuu vocabulary/kanji SRS reviews without internet and send the answers to Renshuu later.

1. Online: on app.renshuu.org run the `rso` bookmark → **Download reviews** → opens this app with today's due items.
2. Offline: study in the app. Answers are stored on the phone.
3. Online again: in the app tap **Send answers to Renshuu**, then run the `rso` bookmark → **Send to Renshuu**. It plays real Renshuu quizzes, answering each question the way you answered offline (correct choice, or "I don't know" when you missed it), and stops if anything doesn't match.

Grammar and sentence schedules are not supported offline.
